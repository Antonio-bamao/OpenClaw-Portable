OpenClaw Portable

常见问题

这页写给第一次使用的人。先看自己遇到的现象，再按步骤处理；不要先去改文件或手动删目录。

Windows 拦截程序 密码和换电脑 服务启动不了 模型没有回复 飞书配对码失败 微信扫码和换电脑 QQ / 企业微信 更新、恢复、U 盘迁移

Windows 提示“智能应用控制已阻止可能不安全的应用”

看到什么：双击启动器时，Windows 弹窗说无法确认应用编写人。

为什么：这是 Windows 对未签名程序的保护，不代表你的密码错了，也不是 OpenClaw 已损坏。

怎么做：
  1. 先确认这个程序来自你信任的 OpenClaw Portable 包，不要为了运行未知来源程序而关闭系统防护。
  2. 核对发布页、版本号和压缩包来源；如果发布方提供校验值或签名，先完成校验。
  3. 如果公司电脑由管理员管控，请联系管理员放行。
  4. 确认来源可信后，再按 Windows 弹窗里的“更多信息 / 仍要运行”路径放行当前程序。
  5. 如果系统策略完全阻止运行，请优先使用已代码签名的新版本或请管理员处理。

长期解决办法是发布方给程序做代码签名。反复重新打包不一定能彻底消除这个提示。

管理密码、保险箱、换电脑

看到什么：首次向导要求设置密码，或者启动时弹出“启用/解锁本地保险箱”。

为什么：这个密码用于保护 API Key 和飞书、QQ、企业微信等渠道凭据。换电脑时，原电脑保存的免密钥不可用，所以需要输入密码。

怎么做：
  1. 第一次使用：在首次向导里设置管理密码。
  2. 旧配置升级：如果弹出“启用本地保险箱”，设置一次密码即可，程序会迁移已有配置。
  3. 换电脑：输入同一个管理密码；如果是自己的电脑，可以勾选信任此电脑。
  4. 忘记密码：无法找回已加密的 Key，只能恢复出厂后重新配置。

服务启动不了、一直启动中、端口变了

看到什么：启动按钮点了很久没好，或监听地址从 18789 变成了别的端口。

为什么：首次启动可能需要几十秒；如果原端口被占用，程序会自动换到可用端口。

怎么做：
  1. 先看“启动日志”，看到 [gateway] ready 表示服务已经起来。
  2. 如果端口变了，直接用界面上显示的新地址，不需要手动改。
  3. 如果日志出现明显错误，点击“导出诊断”，把诊断包发给维护者。
  4. 如果刚更新过程序，先完全退出再重新打开。

WebUI 能打开，但模型不回复或提示 Key 有问题

看到什么：聊天页面能打开，但发送消息后没有正常回复。

为什么：常见原因是 API Key 为空、模型名填错、接口地址填错，或当前网络访问不了模型服务。

怎么做：
  1. 点击“重新配置”，确认 Provider、接口地址、模型名和 API Key。
  2. 保存后重新启动服务。
  3. 如果换了电脑，先解锁本地保险箱，再启动服务。
  4. 仍失败时，导出诊断给维护者，不要把 API Key 直接发给别人。

飞书发消息后回复“access not configured”或配对码审批失败

看到什么：飞书机器人给出用户 ID 和 pairing code，或者命令行显示 No pending pairing request found。

为什么：OpenClaw 需要确认谁可以使用机器人。配对码会过期，重启程序或重新发消息后旧码也可能失效。

怎么做：
  1. 在飞书里重新给机器人发一句话，拿最新的 pairing code。
  2. 只使用最新一次机器人回复里的审批命令。
  3. 确认命令是在当前这个 OpenClaw Portable 目录里执行的。
  4. 审批成功后，再在飞书里发一条普通消息测试。

如果只是想确认飞书通道是否连上，看启动日志里是否出现飞书 WebSocket 已连接的信息。

微信扫码窗口黑屏、扫码后没反应、换电脑后要重新扫码

看到什么：点击“扫码登录”后先出现黑窗口，或者换电脑后微信通道显示需要确认登录。

为什么：微信登录依赖当前电脑环境。新电脑上原来的登录态通常不能直接搬过去。

怎么做：
  1. 点击“扫码登录”后先等一会儿，二维码或错误日志可能需要几十秒。
  2. 手机扫码后，回到 OpenClaw 点击“确认已扫码”。
  3. 如果换电脑，重新扫码是正常现象。
  4. 如果窗口一直黑屏没有任何输出，关闭黑窗口，再重新点“扫码登录”。

QQ 或企业微信配置好了，但还是不能用

看到什么：状态停在“待启用”“需重新启用”或“配置无效”。

为什么：保存凭据只代表 OpenClaw 记住了配置，启用才会写入当前运行时。换电脑后也需要重新启用一次。

怎么做：
  1. 先点击对应渠道的“接入帮助”，按平台要求创建机器人或应用。
  2. 填入 AppID、AppSecret、Bot ID 或 Secret 后，先检查配置。
  3. 检查通过后点击“启用”。
  4. 换电脑后如果显示“需重新启用”，直接重新启用，不要重新创建机器人。

更新、恢复出厂、U 盘插到另一台电脑

看到什么：更新后要重新打开；恢复出厂后进入首次向导；U 盘换电脑后要求密码或重新扫码。

为什么：程序文件和用户状态是分开的。更新主要替换程序文件；状态保存在 state 里。

怎么做：
  1. 更新后完全退出 OpenClaw，再重新打开。
  2. 恢复出厂会清空启动器配置，请确认真的要重来再点。
  3. U 盘换电脑后，先输入管理密码解锁保险箱。
  4. 微信通常需要重新扫码；飞书、QQ、企业微信按界面提示重新连接或启用。
